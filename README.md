# Sendglass
>
> Let's capture a quiet realization, a midnight promise, or a fleeting feeling, and send it forward to a specific day in the near future. A short-term time capsule PWA where your words return only when the sand runs out—a perfectly timed gift from the person you used to be.
>

**Try it:** [richardlaiis.github.io/sendglass](https://richardlaiis.github.io/sendglass/)

## Quickstart

Requires Node.js 24+.

```sh
npm install
npm run dev      # http://localhost:5173
npm test         # unit tests
npm run lint     # ESLint + Prettier
npm run build    # production build into dist/
```

Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`
(in the repo settings, set Pages → Source to "GitHub Actions").
